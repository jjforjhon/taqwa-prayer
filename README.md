# 🕌 Taqwa — Salah & Worship Tracker

A beautiful Apple-style website for Muslims to track their **salah (prayer)** and **worship** based on **Salafi Islam**.

## Features

- **🕌 Prayer Tracker** — Track all 5 daily prayers + Sunnah Mu'akkadah
- **📿 Adhkar** — Morning, Evening, Sleep, and Masnoon Du'as with authentic hadith sources
- **📖 Quran Tracker** — Log reading sessions, track Juz progress and Khatmah count
- **📊 Stats Dashboard** — Streak, weekly chart, perfect days, and more
- **💡 Daily Wisdom** — Quranic verses and prophetic guidance

## Based On

- The **Quran** and **Sunnah** upon the **Manhaj of the Salaf**
- All adhkar sourced from Sahih Bukhari, Sahih Muslim, Tirmidhi, and the Quran

## Live Demo

🔗 [taqwa-prayer.netlify.app](https://taqwa-prayer.netlify.app)

## Tech

- Pure HTML, CSS, JavaScript — zero dependencies
- Apple-inspired design with dark mode, glass morphism, and smooth animations
- LocalStorage persistence — data stays on your device
